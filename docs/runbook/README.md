own page, `ci.md`, holds the table of workflows. A citation that gives a heading or a named
paragraph (`runbook.md, "Bench baseline"`) finds its page here. Two parts are called "Release
download counts": the daily record that `downloads.yml` keeps, and what GitHub counts as a
download.
