# Roadmap

Where Vimma stands and what comes next. Linux comes first and macOS on Apple Silicon is
supported; Windows is not planned.

## The backlog

The backlog is GitHub issues, one per planned feature:
[`label:planned`](https://github.com/vimma-browser/vimma/issues?q=is%3Aissue+is%3Aopen+label%3Aplanned),
tracked on the [Vimma roadmap](https://github.com/orgs/vimma-browser/projects/1) board (Planned,
In progress, Done). Each issue links its spec and lists the spec's open questions;
[specs/README.md](specs/README.md) describes how a spec moves from draft to implemented. This page
keeps the milestones and their order only.

Every Firefox release brings an upstream rebase, which the upstream autopilot turns into a tested
pull request ([ADR-015](adr/015-upstream-autopilot.md)). Keymap changes go one pull request at a
time, each regenerating the bindings docs and the help snapshot.

## Risks

| Risk                                                                              | Likelihood          | Mitigation                                                                                                                                                                                                                                           |
| --------------------------------------------------------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Rebase pain: upstream front-end files change and the `.patch` hunks stop applying | High, every release | Own files and minimal patches ([ADR-003](adr/003-own-files-minimal-patches.md)); the autopilot tries first (`upstream.yml`); the Beta canary finds breakage two weeks early (`upstream-beta.yml`); the quarterly patch audit; [rebase.md](rebase.md) |
| A full Firefox build is too slow for every pull request                           | High                | Pull requests test artifact builds ([ADR-010](adr/010-pr-artifact-builds.md)); full builds run nightly and for releases, on GitHub-hosted runners ([build-supply-chain](specs/build-supply-chain.md))                                                |
| Split view destabilises tab selection, focus or the address bar                   | High                | Firefox's own, tested split view ([ADR-013](adr/013-split-on-firefox-split-view.md)); a mochitest for every pane operation; `ctrl+b z` to zoom out of a broken layout                                                                                |
| Insert-mode detection is wrong on complex editors (Google Docs, Monaco)           | Medium              | Actor heuristics, per-site overrides in `config.toml`'s `[sites]`, and the live site-compatibility suite ([site-compat](specs/site-compat.md))                                                                                                       |
| Surfer is a small project                                                         | Medium              | It is a thin Node CLI over `mach`; it can be forked into `tools/` if it stalls                                                                                                                                                                       |
| Scope creeps toward a general-purpose browser project                             | Medium              | Every feature starts as a spec; new ideas wait as `planned` issues                                                                                                                                                                                   |
| Hidden tabs slow down with hundreds of tabs across workspaces                     | Low                 | Firefox handles hidden tabs well; key-to-paint over 200 tabs is measured in `browser_vimma_perf.js`                                                                                                                                                  |
