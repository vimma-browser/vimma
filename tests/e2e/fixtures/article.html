Reading on the web

Most of what people copy from a web page is one block of text: a paragraph to quote, a list item to keep, a code sample to run.

Element focus puts a label on every block on screen. Typing a label outlines the block; y copies it at once, and v selects it in copy mode, where the usual motions adjust the selection first.

  • Paragraphs, headings and list items.

  • Quotes and table cells.

    Code blocks, copied exactly as shown.

  • Captions and summaries.
A block is what the page's own elements say it is.
